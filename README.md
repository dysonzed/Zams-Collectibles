# Zam's Collectibles

A mod for [Probably Stolen](https://store.steampowered.com/app/4348910/) that adds collectibles from Zamco Electronics, starting with the Aug Warriors trading card game: booster packs, cards with hidden condition and grading, a Collector's Box for sealing complete sets, and a card viewer.

Modding reference: [probably-stolen-modding](https://github.com/dragonpan2/probably-stolen-modding).

## Building

```
dotnet build -c Release
```

The build installs the mod into `<game>\Mods\ZamsCollectibles\` (DLL, `manifest.xml`, `preview.png`, `Textures\`, `Localization\`, `Data\`). The game path is `GameDir` in `ZamsCollectibles.csproj`. The game loads mods at startup, so restart it after a build; turn on **Developer mode** for the mod in the Mods menu so rebuilds load without a new approval.

The F8 console and F9 dev menu need an empty `dev.txt` next to `Probably Stolen.exe`. Our debug tools are under F9 > Special > **Zam's Collectibles**.

## Content

- **Card sets**: `Data/sets.json` (rarities, sets, pack contents, cards). No code change needed to add cards.
- **Card art**: 63 x 46 pixel art in `Textures/Items/`, named `art_<set>_<number>.png` (e.g. `art_scrapyard_01.png`), or any name set in the card's `"art"` field. Cards without art show a placeholder.
- **Item sprites**: generated by `tools/make-placeholder-sprites.ps1`; placeholder card art by `tools/make-card-art.ps1`; the preview by `tools/make-preview.ps1`. Run with `powershell -ExecutionPolicy Bypass -File tools\<script>.ps1`.

## Translations

All player-facing text is in `Localization/<locale>.csv` (`en`, `zh`, `fr`, `de`, `ru`, `ja`, `es`, `ptBR`, `ko`, `it`, `pl`). `en.csv` lists every key. Card content is written in English in `sets.json`; any locale file can translate it with these keys, falling back to English:

| Key | Translates |
|---|---|
| `set_<set>_name` | set name |
| `rarity_<rarity>` | rarity name |
| `card_type_<type>` | card type (`card_type_creature`) |
| `card_<set>_<nn>_name`, `_text`, `_flavor` | a card's name, rules, flavour (`card_scrapyard_01_name`) |

`zh.csv` is a machine-assisted draft and needs a native speaker's review.

## Publishing to the Steam Workshop

Not released yet. When it is:

1. Check in the F8 console: `mod-scan zams-collectibles` must show no undeclared capabilities and no hard flags.
2. Bump `<ModVersion>` and `<GameVersions>` in `manifest.xml`, build, and test.
3. Install [steamcmd](https://developer.valvesoftware.com/wiki/SteamCMD), then from the repo folder:
   ```
   steamcmd +login <steam account> +workshop_build_item "%CD%\tools\workshop.vdf" +quit
   ```
   The first run creates the item (hidden, `visibility 2`) and writes its id into `tools/workshop.vdf`: commit that. Later runs update the same item; set `changenote` each time. The first upload asks you to accept the Workshop agreement on the Steam website.
4. Make the item public on its Workshop page (or set `visibility` to `0`) once it has been tested.

A local copy in `Mods\` with the same id overrides a subscribed Workshop copy, so development can continue alongside the published version.
